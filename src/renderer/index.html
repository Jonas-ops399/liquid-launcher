Microsoft-Login
Einmalig nötig, damit du dich anmelden und Welten öffnen kannst. Application (client) ID aus dem Azure-Portal (Microsoft Entra ID → App registrations).
Redirect-URI (in Azure unter „Redirect URI" als Mobile and desktop applications eintragen): https://login.live.com/oauth20_desktop.srf
Anleitung: App in Azure anlegen
  1. portal.azure.com → Microsoft Entra ID → App registrations → New registration
  2. Name, z. B. „Liquid Launcher"
  3. Supported account types: „Accounts in any organizational directory and personal accounts" — zwingend, sonst werden Konten ohne Minecraft gefunden
  4. Redirect URI → Plattform Mobile and desktop applications → den Wert von oben einfügen
  5. Kein Client-Secret anlegen — für eine Desktop-App wird keines gebraucht, und ein Secret landet zwangsläufig im Installer
  6. Application (client) ID kopieren und oben eintragen. Achtung: nicht die Directory (tenant) ID, die sieht ähnlich aus
